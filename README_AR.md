# Elsisi's AI

مشروع بداية لموقع محادثة عربي متوافق مع الهاتف والكمبيوتر.

## التشغيل محلياً
1. ثبّت Node.js إصدار حديث.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى `.env` وأضف إعدادات مزود ذكاء اصطناعي متوافق.
5. نفّذ: `npm start`
6. افتح `http://localhost:3000`

## ملاحظات مهمة
- الواجهة تعمل، لكن الردود الذكية تحتاج مزود API وإعداداته.
- لا تضع مفتاح API في ملفات المتصفح أو تشاركه مع أي شخص.
- لا تنشر الموقع للعامة قبل إضافة حدود استخدام وحماية من الإساءة.
- الخدمات المجانية لها حدود وقد تتغير شروطها.
